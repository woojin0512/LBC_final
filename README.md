# LBC.bio

효원고등학교 생물연구부 LBC의 2026 활동 결과 사이트입니다. 빌드 없이 GitHub Pages에서 제공하는 정적 HTML/CSS/JavaScript입니다.

- `index.html`: 활동 결과와 TTC 패치 관찰, 갤러리
- `archive.html`: 기존 소개·연구 지원·실험 계획·모집 안내
- `archive-original.html`: 업데이트 전 홈페이지 원본 보존
- `assets/`: 제공된 PPT/PDF에서 추출·최적화한 활동 사진
- `SOURCE_NOTES.md`: 결과·사진의 출처 및 해석 범위
- `CNAME`: 기존 `lbc.bio` 연결 유지

메인 페이지의 TTC 최종 결과는 사용자가 지정한 「LBC 학술제」 PPT의 약 7시간 후 발색 기록을 기준으로 합니다. 결과와 예상·계획을 구분했으며, 원본 발표자료 및 개인 생활 기록 전체는 공개 파일로 추가하지 않았습니다.

검증: 데스크톱/390px 모바일 표시, 모바일 메뉴, 3단계 사진 전환, 사진 확대/Esc 닫기, 기존 계획서 확대, 로컬 링크·앵커·접근성 참조, JavaScript 구문 확인.
